# `results/arwlf/holdout-snapshots/`

**What it is.** Holdout root snapshots captured before the regime campaign.

**Purpose in the repository.** Three n=108 roots (seeds 0x4001, 0x5003, 0x6007) and three n=72 roots (0x7201, 0x7203, 0x7207), each as a `.snap` file (not in git), a `.snap.json` metadata file and a capture log. They are the holdout set that tests whether ARWLF's gain generalizes beyond the calibration roots.

**Files directly in this folder:** 18 (besides this README).
