Freeze-input modes are historical collection workflows and were not run here. `scaling_model.py --freeze-inputs` invokes native preflight; `build_results.py --freeze-inputs` refreshes only the older campaign/cutoff subset, not all later additions. Normal reproduction uses the frozen files already provided.

Prepared structural columns concern FiniteSanity. Constructed positives assign coordinates and residues separately without establishing native L1 membership or original-weight consistency. The staged solve uses the production binary-root rule and original-instance verification. Prepared-root ratios and extrapolations establish neither a full-solver speedup nor an improved asymptotic exponent.
