# `paper/template/`

**What it is.** Word templates for the article.

**Purpose in the repository.** `acm_submission_template.docx` is ACM's single-column Word submission template (SHA-256 `05e757a3c93f9cbf9dbca257009d48d141f311b1132f8396b8cdb2fbac9ef0e9`, checked by `paper/build_article.py`). The builder clones it and uses only its styles, numbering, footers and section geometry; its body text uses Linux Libertine O and Linux Biolinum O, which must be installed for faithful rendering. `reference.docx` is the earlier Theory-Focused Research Paper template behind the 13 October build in `../archive/2026-10-13-theory-template/`; the current builder does not read it.
