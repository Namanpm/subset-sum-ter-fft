# Tiled L2 to L1 TER Merge Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Integrate the PDF-specified exact cache-tiled L2-to-L1 arithmetic reporter into Q3REPORT, exact reference and packed merges, and the supported native-width FullTer L2-to-L1 stage.

**Architecture:** `tiled_q3report` remains the sole owner of bucket/window arithmetic.  Its visitor reports canonical entry IDs; existing reference and packed validators construct, audit, canonicalize, and account for parents.  FullTer selects a native-width tiled path only for L2-to-L1 when the shared quotient arithmetic is representable, otherwise it uses the current exact MITM path before emitting output.

**Tech Stack:** C++20, CMake/CTest, MSVC Release and AddressSanitizer builds.

**Spec:** `TER_Tiled_L2_L1_End_to_End_Implementation_Spec.pdf`

## Global Constraints

- No Bloom filter, parallelism, SIMD, tile autotuning, L3 streaming, or NTT changes.
- Tile policy is `min(15, log2(Q))`; use exact power-of-two quotient arithmetic.
- Preserve existing comparator and CSV columns; append only.
- Preserve validators, finalizers, canonical provenance, and independent audits.
- Tiled L2-to-L1 must never materialize an A-times-B pair-record array or a Q-wide lookup table.
- Unsupported FullTer width must fall back before tiled output; a tiled mid-run resource failure remains a failure.
- Do not route L1-to-L0 through tiling.
- Do not commit or push as part of this task.
