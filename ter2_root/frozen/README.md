# `ter2_root/frozen/`

**What it is.** The 29 SHA-256-pinned source files of the frozen root backends.

**Purpose in the repository.** Contains K2, K2_WIDE, QUEUE_DENSE and ARWLF with its dispatcher, and the code they depend on. Pinned by `ter2_root/frozen_root_backends.sha256` and the CTest `ter_frozen_root_backends`; the files are never edited, so every campaign measures the same code. New ideas go into new files elsewhere.

**Files directly in this folder:** 29 (besides this README).  
Repository-wide status of every file: [`LEGACY_MAP.md`](../../LEGACY_MAP.md).
