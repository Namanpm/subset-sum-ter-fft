# `ter2_root/campaign/`

**What it is.** Benchmark harnesses and host helpers for the TER² root line.

**Purpose in the repository.** Holds the executables that produced the paper's numbers: the regime campaign (`ter_arwlf_campaign`), the whole-root run, the staged solve (`ter_arwlf_solve*`), snapshot capture (`ter_root_snapshot_capture`), the hash-join baseline and the pinning helper. They link the frozen backends and are not themselves frozen.
